# Survey Flow

1問ずつ答えていく、ビルド不要のアンケートアプリ。`index.html` をブラウザで開くだけで動きます。

## 質問の種類

`app.js` の `questions` 配列を編集すると、質問を足したり変えたりできます。

| type | 内容 |
|---|---|
| `radio` | 単一選択 |
| `checkbox` | 複数選択 |
| `stars` | ★評価(`max` で段階数) |
| `scale` | 数値スケール(`min`〜`max`、両端のラベル付き) |
| `textarea` | 自由記述 |

## 操作

- マウス・タッチのほか、キーボード(Tab / Space / Enter)でも全質問に答えられます
- 「戻る」で前の質問に戻っても、回答は保持されます
- 回答はこのページ内だけで保持され、どこにも送信されません
